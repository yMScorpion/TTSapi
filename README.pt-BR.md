# TTSapi

Camada FastAPI sobre o StyleTTS2, com autenticação, formatos de áudio, cache, jobs efêmeros, presets e observabilidade. A análise estática confirma 9 rotas, 4 formatos e 7 painéis de visualização; não foram medidos resultados de inferência.
